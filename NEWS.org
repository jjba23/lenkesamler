*[Released]*

** v0.0.14 (2026-11-21)

- The API reference is rendered with Texinfo 7.3, so `dokgen`'s stylesheet applies: the page now has its index, its filter and its definition cards, like the `dokgen` manual. The manifest selected the bare `texinfo` binding (6.8), whose `texi2any` emitted the old definition structure, and nothing in the stylesheet matched it.
- `channels.scm` pins the jointhefreeworld revision that carries `guile-dokgen` 0.9.2.

** v0.0.13 (2026-11-21)

- The API links point at `index.html`, the one page the reference has been since the dokgen migration, rather than at `.../API.html`.
- `channels.scm` pins the jointhefreeworld revision that carries `guile-dokgen` 0.9.1.

** v0.0.12 (2026-11-21)

- The API reference is generated with `dokgen` instead of `documenta`, and rendered as one page: `maak docs` writes `doc/api/index.texi` and `doc/api-dist/index.html`, with `dokgen.css`, `dokgen.js` and the drawn diagrams beside it.
- `channels.scm` pins Guix `5cea8de` and adds the `jointhefreeworld` channel, which is where `guile-dokgen` comes from. `maak test`, `maak repl` and `maak docs` run inside `guix time-machine`, because the manifest names a package that only that channel provides.
- `maak diagrams` renders every mermaid source under `resources/diagrams` to the SVG beside it. `resources/diagrams/run.svg` is the first one: the run the README describes, drawn.
- The `(lenkesamler main)` commentary now walks that run in prose and carries the same mermaid source, so the API reference draws it too.

** v0.0.10 (2026-11-12)

- Builds against the channels this project builds against: the jointhefreeworld collection at v1.0.4, and Guix master `3b4e873`.

** v0.0.9 (2026-11-10)

- The funding file now carries a custom URL that points at [[https://buymeacoffee.com/jjbigorra][Buy Me a Coffee]].

** v0.0.8 (2026-11-10)

- The repository now carries ~.github/FUNDING.yml~, so GitHub shows a Sponsor button that points at [[https://buymeacoffee.com/jjbigorra][Buy Me a Coffee]].

** v0.0.2 (2026-10-22)

A maintenance release: the sources are identical to *v0.0.1*, the first tagged
release, and this tag gives downstream packagers a release to follow.
